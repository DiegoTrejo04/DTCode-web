# DT CODE - Sitio Web Oficial
Este es el repositorio del sitio web de **DT CODE**, una agencia dedicada al desarrollo de software a medida, aplicaciones web y gestión de bases de datos.

## 🚀 Tecnologías usadas
- HTML5
- CSS3 (Diseño responsivo)
- JavaScript

## 🛠️ Servicios proyectados
- Desarrollo de aplicaciones de escritorio (Java)
- Sistemas de Punto de Venta (POS)
- Consultoría en SQL Server y MySQL
